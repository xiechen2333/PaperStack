# PaperStack 📚

> **👋 大家好！本项目是一个由 AI 完全辅助生成的开源小工具。**

**PaperStack 并不是用来替代 Zotero 等文献管理软件的。** 它的定位是文献阅读器的“最佳辅助”——帮你把阅读时的灵感、评分和核心思绪，变成清晰的结构化记录。

平时用 Zotero 看论文，或许会高亮和批注往往到处都是，过一阵子就想不起来重点。这个小工具就是为了解决这个问题：**方便你随时记录下各种 IDEAS、核心方法或是对一篇论文的打分与评价。** 

💡 **最省力的终极用法**：读完论文后，你可以直接让 AI（比如 ChatGPT/Claude）帮你生成一份 Markdown 格式的核心总结，然后一键粘贴到这里，再配上你自己的评分和两句想法，就完成了一篇高质量的阅读记录！

## ✨ 核心亮点

- **专注笔记与灵感提取**：内建四宫格结构，也支持纯净的 Markdown 粘贴。无论是自己写还是用 AI 帮写，都能完美兼容。
- **多维度检索与状态追踪**：
  - **阅读状态与评分**：支持标记“待读”、“在读”、“已读”，并能为其打分（1-10分）。
  - **时间追踪不遗忘**：系统会精准记录你具体哪一天打的分（即读完的时间），结合“最近阅读”功能，你永远清楚最近自己看了些什么。
  - **自由标签**：通过自建标签库（Tags）把跨领域的论文串联起来。
- **保护隐私，数据纯本地**：完全在你的浏览器里运行（基于 IndexedDB），无需注册，数据不用上传云端。
- **AI 清单批量合并**：提示词附带当前完整目录，导入时严格核对分类路径；按标题、DOI、原文链接去重，保留已有笔记。默认只使用已有分类，主动开启后才允许新建文件夹。
- **近期新增**：跨分类汇总批量导入和手动录入的文献，按加入时间倒序查看近 7 / 30 / 90 天或全部新增记录，显示来源和分类路径。
- **随时备份，带走数据**：可以一键导出所有的笔记数据（JSON 格式），方便更换设备或做长期存档。
- **护眼的深色模式**：全局适配了高对比度的护眼深色模式，深夜读 paper 不刺眼。

## 🚀 怎么运行？

这是一个前端单页应用（React + Vite），需要你的电脑上有 Node.js 环境。

1. **装依赖**：
   ```bash
   npm install
   ```
2. **跑起来**：
   ```bash
   npm run dev
   ```

*(💡 如果你是 Windows 并且配置好了环境，直接点开目录下的 `启动文献记录.bat` 也能一键运行！)*

## 💡 怎么用最顺手？

1. **建大纲**：点击左下角按钮进入“管理模式”，建立你的大研究方向（比如：多模态、时间序列）。
2. **读完即记**：配合 Zotero 读完 PDF，切过来点“新文献”，如果是泛读，直接贴上 AI 生成的 Markdown 总结；如果是精读，自己写一写灵感和方法。
3. **记得备份**：每天下班前，随手点一下右上角的“备份”按钮，妥善保存你的知识结晶。

## 批量导入 AI 整理的文献

1. 点击右上角「批量导入」，下载 JSON 模板，或复制 AI 提示词并填入研究方向。
2. 将 AI 的结果保存为 UTF-8 `.json` 文件后上传，也可以直接粘贴 JSON。每次最多 5MB 文件、2000 篇。
3. 检查预览和默认分类，点击「合并 N 篇新文献」。合并后自动进入「近期新增」。

「分类规则」分别展示默认分类与新文件夹策略。清单支持 `link`；填写 `doi` 而未填写 `link` 时，会自动生成 DOI 链接。AI 提示词要求逐篇提供并核对来源链接，无法核实的链接留空。程序检查链接格式，不自动证明网页内容或文献真实性。

```json
{
  "papers": [
    {
      "title": "论文标题",
      "year": "2026",
      "venue": "发表来源",
      "link": "https://example.com/paper",
      "categoryPath": ["研究方向", "子方向"],
      "tags": ["标签"]
    }
  ]
}
```

模板与 AI 提示词只要求 `title`、`year`、`venue`、`link`、`doi`、`categoryPath`、`tags`，其中只有 `title` 必填。批量收集时不要求生成研究问题、方法、结果或个人思考，阅读笔记可之后再填写。`categoryPath` 必须是从根目录开始的文件夹名称数组，逐级匹配已有目录（包括大小写和父子关系）；省略或为空时，必须在界面选择已有的默认分类。路径拼错、不存在或有同级同名歧义时会标为无效，不会自动改投默认分类或新建「未分类」。文献以「待读」状态加入，不导入清单中的 ID、评分或时间。

复制的 AI 提示词包含完整分类路径数组和分类说明，要求使用已有路径；下载模板的示例路径也取自当前目录。无法确定分类时，AI 应留空路径，由你指定默认分类。目录变更后请重新复制提示词；提交合并时会再次按当前目录校验。

确需扩充目录时，主动勾选「允许新建文件夹（仅本次导入）」，核对预览列出的所有新路径，再确认合并。此选项默认关闭，清单内容不能自行开启它。路径校验可阻止虚构文件夹和错误层级，但不能证明文献内容适合某个已有分类；请检查每篇文献的目标分类。

标题忽略大小写、空格和标点后相同，或 DOI / 原文链接相同的条目会跳过；arXiv 的摘要页、PDF 和不同版本视为同一篇。预览会显示匹配的文献，清单内部的重复项也会跳过。无效项标出原因，仅合并有效的新文献。此功能与「恢复备份」不同：批量导入追加新文献，恢复备份替换整个知识库。

「近期新增」记录本功能上线后的真实加入时间，编辑和移动不会重置它。没有加入时间的历史文献仍在「全部文献」及原分类中；恢复新版备份会保留原始加入时间。
